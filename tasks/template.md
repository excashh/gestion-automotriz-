# 📝 Plantilla de Micro-Tarea

Copia y pega este bloque en [`backlog.md`](./backlog.md) cuando quieras registrar una nueva tarea corta:

```markdown
### [TASK-XXX] Nombre corto de la tarea
- **Módulo:** Backend / Frontend / Database / Docs
- **Prioridad:** Alta / Media / Baja
- **Estado:** Pendiente / En Progreso / Completada
- **Descripción:** 
  Explicación breve de lo que se debe hacer en 1-3 oraciones.
- **Criterios de Aceptación:**
  - [ ] Criterio 1 (ej. Campo validado)
  - [ ] Criterio 2 (ej. Endpoint responde 200/400 adecuadamente)
- **Rama sugerida:** `feature/task-xxx-nombre`
```
